# 🧪 Лабораторная работа №8: Публикация первого официального релиза

> **Цель работы:** Провести аудит проекта на чистоту, добавить файл открытой лицензии (MIT License), создать аннотированный тег `v1.0.0` и опубликовать официальный GitHub Release с описанием изменений.

---

## 📋 Пошаговый сценарий

### Шаг 1. Аудит репозитория (Проверка Ground Rules)
Открой терминал в своем учебном проекте:
```bash
cd test-git-lab
git switch main
git pull
```

1. Выполни `git status` и убедись, что рабочая директория чистая (`working tree clean`).
2. Проверь, нет ли в проекте бинарников, логов или забытых файлов `.env`.

---

### Шаг 2. Добавление лицензии (MIT License)
1. Открой свой репозиторий на сайте [github.com](https://github.com).
2. Нажми кнопку **Add file** ➔ **Create new file**.
3. В поле имени файла напиши заглавными буквами: `LICENSE`.
4. Справа появится кнопка: **Choose a license template** — нажми ее.
5. В списке слева выбери **MIT License**.
6. В блоке справа проверь свое имя и текущий год.
7. Нажми зеленую кнопку **Review and submit**.
8. Сделай коммит прямо в ветку `main` с сообщением: `docs: добавить лицензию MIT`.
9. Теперь твой проект официально открыт для сообщества!

---

### Шаг 3. Синхронизация и создание первого тега в терминале
Вернись в консоль на компьютере и скачай файл лицензии:
```bash
git pull
```

Теперь запечатаем текущее состояние проекта в официальный тег **`v1.0.0`**:
```bash
# 1. Создаем аннотированный тег с описанием
git tag -a v1.0.0 -m "Выпуск первой стабильной версии проекта v1.0.0"

# 2. Проверяем созданный тег
git tag --list -n

# 3. Отправляем тег в облако на GitHub!
git push origin --tags
```

---

### Шаг 4. Публикация официального релиза на GitHub
1. Перейди на страницу своего репозитория в браузере.
2. В правой боковой колонке найди раздел **Releases** (он пока пустой) и нажми **Create a new release** (или перейди во вкладку Releases).
3. В графе **Choose a tag** выбери отправленный тег `v1.0.0`.
4. В графе **Release title** напиши: `v1.0.0 — Первый официальный релиз`.
5. Нажми волшебную кнопку в правом верхнем углу редактора: **Generate release notes**.  
   *GitHub сам составит красивый список всех изменений и укажет авторов коммитов!*
6. Убедись, что стоит галочка **Set as the latest release**.
7. Нажми зеленую кнопку **Publish release**.

---

### Шаг 5. Любуемся результатом 🎉
Открой главную страницу своего репозитория:
* В правом сайдбаре в блоке **Releases** красуется зеленый бейдж **v1.0.0 Latest**!
* В блоке **License** гордо отображается ссылка на **MIT License**.

Ваш проект полностью оформлен по всем мировым стандартам профессиональной разработки!

---

## ✅ Критерии успешного выполнения
1. В корне репозитория присутствует файл `LICENSE` (MIT).
2. В репозитории создан и отправлен тег `v1.0.0`.
3. Опубликован официальный Release со сгенерированным списком изменений.

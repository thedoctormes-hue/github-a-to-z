# 🧪 Лабораторная работа №2: Локальный полигон (Консоль & Push)

> **Цель работы:** Пройти боевое крещение терминалом: настроить безопасную связь между компьютером и GitHub, инициализировать локальный проект, сделать коммиты и проверить двустороннюю синхронизацию (`push` и `pull`).

---

## 📋 Пошаговый сценарий

### Шаг 1. Проверка окружения
Открой терминал и убедись, что Git настроен:
```bash
git --version
git config user.name
git config user.email
```
*Убедись, что email совпадает с почтой твоего аккаунта на GitHub!*

---

### Шаг 2. Проверка связи с GitHub
Выполни проверку авторизации (SSH или GitHub CLI):
```bash
# Если настраивал SSH:
ssh -T git@github.com

# Либо если настраивал gh CLI:
gh auth status
```
Ты должен увидеть сообщение об успешной авторизации под своим логином.

---

### Шаг 3. Создание проекта на компьютере
1. Создай новую папку для учебного проекта и перейди в нее:
   ```bash
   mkdir test-git-lab
   cd test-git-lab
   ```
2. Инициализируй репозиторий:
   ```bash
   git init
   ```
3. Создай файл `README.md` с описанием проекта:
   ```bash
   echo "# Мой локальный учебный полигон" > README.md
   ```
4. Добавь файл в индекс и сделай свой **первый коммит**:
   ```bash
   git add README.md
   git commit -m "feat: начальная инициализация проекта"
   ```

---

### Шаг 4. Второй коммит (закрепляем привычку)
1. Создай второй файл (например, простой текстовый файл или скрипт `hello.py` / `index.html`):
   ```bash
   echo "print('Привет из локального терминала!')" > main.py
   ```
2. Проверь статус:
   ```bash
   git status
   ```
3. Добавь файл и сделай **второй коммит**:
   ```bash
   git add main.py
   git commit -m "feat: добавлен стартовый скрипт"
   ```
4. Посмотри историю коммитов:
   ```bash
   git log --oneline
   ```
   Ты должен увидеть 2 четких аккуратных коммита.

---

### Шаг 5. Отправка на GitHub
1. Перейди в браузер на GitHub и нажми `+` ➔ **New repository**.
2. Назови его `test-git-lab`.
3. Оставь его **Public**, галочки добавления файлов **НЕ ставь**.
4. Скопируй SSH-ссылку на репозиторий.
5. Привяжи репозиторий и запушь код:
   ```bash
   git remote add origin git@github.com:твой-логин/test-git-lab.git
   git branch -M main
   git push -u origin main
   ```
6. Открой репозиторий в браузере: оба файла и оба коммита должны отобразиться на сайте.

---

### Шаг 6. Двусторонняя синхронизация (Тест Pull)
1. На странице репозитория на GitHub нажми на файл `README.md` и нажми иконку карандаша (Edit this file).
2. Допиши в конец файла строку:  
   `*Изменение внесено через сайт GitHub для проверки git pull*`
3. Нажми зеленую кнопку **Commit changes...** внизу.
4. Теперь вернись в терминал на компьютере и выполни:
   ```bash
   git pull
   ```
5. Открой файл `README.md` на компьютере — добавленная на сайте строка появилась на твоем диске!

---

## ✅ Критерии успешной сдачи работы
1. В репозитории `test-git-lab` на GitHub есть минимум 3 коммита:
   * 2 коммита сделаны локально через терминал.
   * 1 коммит сделан через сайт GitHub.
2. Локальная папка на компьютере содержит актуальную версию файла `README.md` после выполнения `git pull`.
3. Команда `git status` на компьютере сообщает: `nothing to commit, working tree clean`.

# 🧪 Лабораторная работа №1: Оформление профиля разработчика

> **Цель работы:** Познакомиться с веб-интерфейсом GitHub, создать секретный репозиторий визитки, освоить горячую клавишу `.` (VS Code for Web) и базовый синтаксис Markdown.

---

## 📋 Инструкция по шагам

### Шаг 1. Создание профильного репозитория
1. Войди в свой аккаунт на GitHub.
2. В правом верхнем углу нажми на значок `+` и выбери **New repository**.
3. В графе **Repository name** напиши свой точный логин GitHub (например, если твой ник `anna-code`, имя репозитория должно быть строго `anna-code`).
4. Убедись, что выбрано:
   * [x] **Public** (Публичный)
   * [x] **Add a README file** (Добавить файл README)
5. Нажми **Create repository**.

---

### Шаг 2. Запуск онлайн-редактора
1. Находясь на странице созданного репозитория, нажми клавишу точки (`.`) на английской раскладке клавиатуры.
2. Откроется интерфейс VS Code прямо в браузере.
3. В левой панели проводника нажми на файл `README.md`.

---

### Шаг 3. Заполнение шаблона
Замени стандартный текст в `README.md` следующим содержимым (заполни свои реальные данные):

```markdown
# 👋 Привет! Я — [Твое Имя]

Начинающий разработчик. Изучаю основы программирования и командной разработки.

---

### 🔭 Что я сейчас делаю
- 📚 Изучаю: [например: Python, веб-разработку, основы баз данных]
- 🎯 Цель: освоить Git и собрать портфолио из первых проектов
- 🛠️ Инструменты: VS Code, GitHub, терминал

---

### 📌 Мои цели на этот месяц
- [ ] Оформить профиль на GitHub
- [ ] Научиться работать с Git через консоль
- [ ] Написать и выложить свой первый проект

---

### 📫 Как со мной связаться
- Telegram: [@твой_ник](https://t.me/твой_ник)
- Почта: [твой_email@example.com](mailto:твой_email@example.com)
```

---

### Шаг 4. Фиксация изменений (Commit)
1. Нажми на иконку **Source Control** в левой панели (третья сверху, с синей цифрой `1`).
2. В строке сообщения напиши: `feat: оформление профиля разработчика`.
3. Нажми синюю кнопку **Commit & Push** (или галочку).
4. Перейди на страницу `https://github.com/[твой-логин]` и убедись, что визитка отображается красиво и аккуратно.

---

## ✅ Критерии успешного выполнения
1. Репозиторий имеет статус **Public** и называется в точности как твой никнейм.
2. В профиле отображается заголовок, краткое описание, цели на месяц и контактная ссылка.
3. В тексте правильно применен Markdown: заголовки разного уровня, маркированные списки, чек-боксы и ссылки.

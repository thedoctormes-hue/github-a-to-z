и проект следует принципам [Семантического версионирования](https://semver.org/lang/ru/).

## [Unreleased]

### 🛰️ Спецгайд скоростной разведки репозиториев (Repo Reconnaissance 2026)
- **Создано руководство `docs/repo-reconnaissance.md`**: Разработан 60-секундный протокол аудита и декомпозиции любых чужих репозиториев. Включает витальные маркеры жизнеспособности (pulse, releases, bus factor), горячие клавиши веб-орбиты (`.`, `t`, `b`, `/`, `y`), рентген манифестов зависимостей, поиск точек входа, тесты как честную спецификацию, бесконтактный запуск в GitHub Codespaces и чек-лист красных флагов.
- **Сквозная интеграция рекогносцировки**: Ссылки на спецгайд интегрированы в главную витрину `README.md`, навигатор `CHEATSHEET.md`, хаб `docs/en/README.md`, вводный модуль `docs/00-intro/README.md` и главу аудита `docs/14-security-insights/README.md`.

### 🤖 Стандарт AI-Readiness, LLM Context & Repomix
- **Внедрены спецификации `llms.txt` и `llms-full.txt`**: Официальные манифесты по открытому стандарту `llms.txt` для LLM-агентов, RAG-систем и AI-поисковиков (Perplexity, ChatGPT, Claude) с полной картой курса и токено-эффективным контекстом.
- **Интегрирован конфигурационный файл `repomix.config.json`**: Предустановленный профиль для инструмента Repomix, позволяющий упаковать весь репозиторий в единый чистый Markdown-контекст одной командой `npx repomix`.
- **Интерактивные AI Prompt Presets в `README.md`**: Размещены готовые блоки промптов (персональный AI-ментор, строгий экзаменатор по Git, запуск мгновенного дайджеста через Gitingest).

### 🎭 Протокол взаимодействия для AI-агентов (The AI Agent Protocol)
- **Создан стандарт `AGENTS.md`**: Официальный манифест инструкций для автономных и интерактивных агентов (Cursor, Windsurf, Claude Code, Aider, Antigravity, Copilot Workspace). Включает «Протокол экскурсовода» (The AI Concierge), стандарты чистой архитектуры, правила Conventional Commits и обязательную валидацию гиперссылок.
- **Обновлен `.github/copilot-instructions.md`**: В конфигурацию GitHub Copilot интегрирован протокол ментора и санитарные правила верификации графа ссылок.

### 🎯 Персонализированная навигация (Choose Your Track)
- **Интерактивная развилка ролей в `README.md`**: Спроектированы 4 целевых маршрута прохождения курса (Новичок в IT, Production-разработчик, DevOps & Security Цитадель, AI-инженер & Вайбкодер 2026) с указанием глав и измеримых результатов.

## [1.7.0] - 2026-10-13

### 🌐 Интернационализация (i18n Hub) & Мировое сообщество
- **Создан координационный хаб интернационализации `docs/en/README.md`**: Развернуто официальное англоязычное руководство, дорожная карта перевода модулей и пошаговый гайд для контрибьюторов со всего мира.
- **Интеграция переключателя языков в `README.md`**: Добавлен двуязычный навигационный бар (Русский / English) и бейдж перевода в главную витрину курса.

### 🤖 Автоматический робот-ассистент & Валидатор PR (Graduate PR Verifier & Welcome Bot)
- **Развернут воркфлоу `.github/workflows/graduate-verifier.yml`**: По мотивам лучших мировых Open Source практик внедрён автоматический робот-ассистент для встречи и верификации Pull Requests выпускников.
- **Внедрен скрипт санитарного контроля `scripts/verify_graduate_pr.py`**: Реализует Scope Guard (гарантирует изоляцию изменений строго файлом `GRADUATES.md`), Anti-Vandalism (блокирует удаление или изменение существующих записей выпускников) и валидацию формата строки таблицы со ссылкой на GitHub-профиль.
- **Интегрирован Welcome Bot с автопровижинингом лейбла `graduate`**: При успешной проверке робот оставляет теплое поздравление от имени проекта в PR и маркирует его специальным золотым лейблом.

### 🎓 Дипломный тренажёр & Зал славы выпускников (Graduates Hall of Fame)
- **Создан интерактивный дипломный тренажёр первого PR в `GRADUATES.md`**: По мотивам мирового бенчмарка `firstcontributions/first-contributions` развернута официальная дипломная песочница и Зал Славы выпускников курса. Включает детальное пошаговое руководство (Fork ➔ Branch ➔ Edit ➔ Commit ➔ Push ➔ PR ➔ CI ➔ Merge) для преодоления психологического барьера первого шага в Open Source.
- **Сквозная интеграция тренажёра выпускников в структуру курса**: Добавлены ссылки на `GRADUATES.md` и бейдж в главную витрину `README.md`, финал теоретического Модуля 14 (`docs/14-security-insights/README.md`), практический полигон Лабораторной №14 (`labs/lab-14-security-insights/README.md`), навигатор `CHEATSHEET.md` и регламент контрибьюторов `CONTRIBUTING.md`.
- **Актуализация регламента `CONTRIBUTING.md`**: Очищены устаревшие упоминания ветки `init`, утверждена базовая ветка `main`, добавлена семантическая ветка `graduate/<username>` и специальный раздел о сдаче диплома.

### ✈️ Аварийные лётные правила & Шорткаты GitHub (Flight Rules & Superpowers)
- **Развернут блок «Аварийные лётные правила (Git Flight Rules)» в `CHEATSHEET.md`**: По канону аварийных чек-листов NASA и `k88hudson/git-flight-rules` добавлены 8 сценариев катастроф с однострочными рецептами спасения (коммит в main, случайный коммит секретов, откат reset --hard через reflog, откат PR в main через revert -m 1, бинарные конфликты, cherry-pick и abort).
- **Внедрен раздел «Секретные шорткаты и URL-магия GitHub» в `CHEATSHEET.md`**: По канону `tiimgreen/github-cheat-sheet` систематизированы горячие клавиши веб-интерфейса (`.`, `t`, `y`, `l`, `b`, `?`), скрытые параметры URL (`?w=1`, `.diff`, `.patch`, сравнение веток) и продвинутый Markdown в Issues/PR (спойлеры `<details>`, `diff`-подсветка, автозакрытие тикетов).

### 🛡️ Санация антипаттернов & Устранение тарифных слепых зон (Red Team Audit)
- **Создан корневой `.gitignore`**: Первая линия обороны проекта — исключение системного мусора (.DS_Store, Thumbs.db), артефактов Python (__pycache__, venv), секретов (.env) и кэша IDE.
